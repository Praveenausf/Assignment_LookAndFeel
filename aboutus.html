Building This Website

This site is the user interface for a fan and management portal for Infusion, an indie rock band from Tampa, Florida. Fans can meet the band, browse albums and see upcoming shows; the band's manager can maintain tour dates; and everyone can explore streaming and ticket statistics.

I planned four pages that share the same top menu so navigation is consistent. The tour, streaming and song data is kept in one file (js/data.js) so it can later be replaced by a real database without changing the pages.

  • Home: band overview, members, albums and upcoming shows built from the data file.
  • Manage Tours: a form that mocks Create, Read, Update and Delete for tour dates, with input checks and search.
  • Analytics: line, doughnut and bar charts plus summary numbers.
